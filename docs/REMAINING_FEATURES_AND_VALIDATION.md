## Intentionally not fabricated
A transformer-specific IEC 60076-7 thermal model cannot be credibly enabled from the CEA 100 MVA, 220/33 kV rating row alone. It needs the selected OEM's guaranteed technical particulars and model parameters, including rated top-oil rise, winding hot-spot gradient, oil and winding time constants, load-loss/no-load-loss relationship or equivalent model inputs, cooling-stage characteristics, ambient conditions and applicable loading assumptions. The present scripted scenario remains a demo sequence.

Likewise, no automatic DGA, tan-delta, PD, FRA, furan or bushing diagnosis is generated from arbitrary thresholds. Those assessments require the applicable standard method, test conditions, baselines, transformer design and expert validation.

## Before calling this operationally realistic
1. Obtain one OEM nameplate, guaranteed technical particulars, outline drawing and instruction manual for an actual 100 MVA 220/33 kV unit.
2. Replace assumed cooling/tank/tap-changer details with those documents.
3. Configure actual thermal parameters and implement/validate the applicable IEC 60076-7 model.
4. Confirm OEM/utility alarm and trip settings; keep them separate from dashboard warnings.
5. Validate DGA and oil interpretation against IEC 60599, IEEE C57.104 and IEC 60422 using actual sampling metadata and trends.
6. Validate bushing, OLTC, PD and FRA interpretation with the applicable standards and OEM procedures.
7. Add authentication/authorization before exposing write APIs outside a trusted demo network.
8. Run frontend build, backend tests, Flyway migration against a disposable MySQL database and browser end-to-end tests.
